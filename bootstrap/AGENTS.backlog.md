# Backlog/increment workflow

A backlog of increments is managed under `backlog/`:

- an increment is tracked using an increment file
- increment files move between sub-folders depending on their state
- increment files move between states: maybe-later <-> todo -> in-progress -> done
- an increment file is self-contained and provides workflow instructions

When creating a new increment:

- You MUST follow instructions in `Instruction: new increments` in `backlog/increment-template.md`
- You MUST make a copy of the file `backlog/increment-template.md`
- You MUST follow the file naming instructions

When scoping, designing, planning, implementing or completing an increment:

- You MUST follow relevant instructions in the increment file
